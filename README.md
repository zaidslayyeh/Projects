## Project 2: Magnetoelastic Sensor 
- Designed and prototyped a wearable compression shirt utilizing a magnetoelastic generator (MEG) to monitor respiratory patterns for clinical and athletic use
- Designed and fabricated a custom signal amplification circuit, optimizing coil geometry and practicality to maximize voltage sensitivity to anatomical motion using MEG, implementing design controls, utilizing oscilloscope for signal readings
- Refined signal output through iterative prototyping and data analysis via an Arduino acquisition system
- Contributed to experimental design, verification testing, user-centered design, technical troubleshooting, and data collection protocols
