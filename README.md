## Project 1: Senior Design Project
- Designed a Hello Robot Stretch 3 mobile manipulator with a custom myoelectric (EMG) control interface, enabling semi-autonomous "human-in-the-loop" robotic operation
- Made to assist in feeding of individuals with upper limb mobility impairments
- Users could lightly flex a muscle anywhere on the body and could have the ability to feed themselves with a robot
- Worked on product workflow design, coded the filter and data processing logic, python scripts for robot commanding, and designed end effectors to be placed on the robot for costume feeding functionality
## Project 2: Magnetoelastic Sensor 
- Designed and prototyped a wearable compression shirt utilizing a magnetoelastic generator (MEG) to monitor respiratory patterns for clinical and athletic use
- Designed and fabricated a custom signal amplification circuit, optimizing coil geometry and practicality to maximize voltage sensitivity to anatomical motion using MEG, implementing design controls, utilizing oscilloscope for signal readings
- Refined signal output through iterative prototyping and data analysis via an Arduino acquisition system
- Contributed to experimental design, verification testing, user-centered design, technical troubleshooting, and data collection protocols
## Project 3: LED Coordination Sequence and Video Game on Arduino
- Developed an Arduino button-counter program that detects timed button presses, converts the resulting count to binary, and displays the binary value across multiple LEDs using iterative GPIO control and bitwise logic.
- Built a game from scratch using a toggle stick, setting up sinusoidal boundary limits and implementing a functionality for the game
- A point needs to stay between two boundaries and if it exceeds any of these lower or higher boundaries, the game will reset and allow you to play again
## Project 4: Mechanical Redesigning of Testing Aid (No Correlated PDF)
- An aid we used for testing on the manufacturing floor was experiencing repeated breaking at a joint, I was tasked with redesigning the aid in SolidWorks while maintaining specs and functionality, to prevent this common failure.
- Introduced design changes that improved structural support and executed repeatability and drop testing with the aid to ensure the new design change had solved the issue before committing the design change into production
- Set up the .STL file along with the specific material, infill percentage, and printing orientation required for strength needs
