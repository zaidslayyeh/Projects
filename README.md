## Project 1: Senior Design Project
- Designed a Hello Robot Stretch 3 mobile manipulator with a custom myoelectric (EMG) control interface, enabling semi-autonomous "human-in-the-loop" robotic operation
- Made to assist in feeding of individuals with upper limb mobility impairments
- Users could lightly flex a muscle anywhere on the body and could have the ability to feed themselves with a robot
- Worked on product workflow design, coded the filter and data processing logic, python scripts for robot commanding, and designed end effectors to be placed on the robot for costume feeding functionality
